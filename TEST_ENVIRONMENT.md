# OrçaFácil Premium Test

Ambiente separado para testar novas funcionalidades antes de promover alterações para a branch `main` e para o OrçaFácil Pro principal.

Branch de testes: `orcafacil-premium-test`

- Não promover alterações para `main` sem validação no ambiente de teste.
- Manter banco e variáveis de ambiente de teste separados do ambiente principal quando configurados na Vercel.
